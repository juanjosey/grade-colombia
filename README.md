# Colombia GRADE Network — Sitio web oficial

Sitio de la Colombia GRADE Network, entidad oficial del [GRADE Working Group](https://www.gradeworkinggroup.org).

## Estructura

- `index.html` — página principal (bilingüe ES/EN)
- `talleres.html` — historial de talleres y formación
- `mixed-methods.html` — micrositio del GRADE Mixed Methods Project Group

Los tres archivos son autocontenidos (CSS, JS e imágenes incrustadas): no requieren build ni dependencias. Cualquier hosting estático los sirve tal cual.

## Publicación

Publicado con GitHub Pages desde la rama `main`. Dominio final previsto: `co.gradeworkinggroup.org` (subdominio gestionado por el GRADE Working Group vía CNAME).
